# Аэ))

Прив, тут представлена базовая апишка с возможностями:
- получать лист сущностей
- создавать новые 
- удалять 
- получать конкретную

--- 

чтобы запустить все модули проекта, тебе нужно запустить следующие команды:

- чтобы запустить фронтенд:
```bash
make start_web 
```
- чтобы запустить бек:
```bash
make start_api
```
делается это кстати в отдельных терминалах, прям открываешь новый под каждый модуль

может быть, на этапе запуска бекенда, будут возникать ошибки, скорее всего у тебя не установлен либо докер либо поетри, посмотри команду в интере как его установить у тебя 

---

после того, как все таки запустишь, по этому адресу будет доступна документация по ручкам, которые можешь дергать:
- http://localhost:8000/docs#/

также, документацию по отправке запросов через аксиос, можешь использовать этот сайт:
- http://axios-js.com/docs/index.html

и так, твоя задача: 
- с помощью [v-data-table](https://vuetifyjs.com/en/components/data-tables/basics/#usage) расположить в таблице информацию о сущностях, которые будут добавлены. 
> кстати, ни одной лабубу сначала не будет, только после того, как ты создашь

- возможность с помощью формы создавать новые лабубу, используй [v-text-field](https://vuetifyjs.com/en/components/text-fields/#usage)
    - и кнопку, после нажатия которой будет делаться запрос на апишку, для создания новой сущности через post запрос
